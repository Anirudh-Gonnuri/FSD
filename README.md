# 📘 Full Stack Development – Lab Programs

This repository contains all the **lab programs and practical exercises** completed as part of my **Full Stack Development course**.  
The labs focus on building a strong foundation across **frontend, backend, and web fundamentals**, with emphasis on hands-on implementation.

## 🔹 Topics Covered

### HTML5 & CSS3
- Semantic HTML elements
- Forms, audio, and video
- CSS selectors and pseudo-classes
- Transitions and basic animations
- Responsive layouts using Flexbox and Grid

### Tailwind CSS
- Utility-first CSS framework
- Responsive grid systems
- Prebuilt UI components

### JavaScript
- DOM manipulation
- Form validation
- LocalStorage and SessionStorage
- Fetch API with real API integration

### Frontend Projects
- Responsive portfolio website
- Interactive UI components
- Search, filter, sort, and pagination features

### Version Control
- Git fundamentals (commit, rollback, branching)
- GitHub remote repositories and collaboration

## 🔹 Purpose of This Repository
- To document lab work completed during the course
- To demonstrate practical understanding of full stack concepts
- To serve as a reference for revision and future projects

Each folder corresponds to a specific lab or concept, with a clear and modular project structure for easy navigation.
